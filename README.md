One one-line comedy joke, 149 characters, written deterministically to `/output/entry.txt` for make.fun's "One-Liner Marathon" bounty.

## Run it

```sh
python3 main.py
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
